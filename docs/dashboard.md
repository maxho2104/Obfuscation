# Вкладка «Дашборд»

Статус: реализовано (2026-11-17). Документ описывает фактическую вкладку,
источники данных и поведение при изменении размера окна.

## 1. Назначение

«Дашборд» — обзорный экран для быстрой оценки состояния работы за выбранный период.
Он не заменяет вкладку «Статистика» и отвечает на вопросы «сколько сделано», «как
распределены задачи» и «как меняется динамика» без построения таблиц вручную.

Вкладка доступна обеим ролям:

- филиал видит только свой филиал;
- головной офис видит все филиалы и может выбрать один в фильтре.

## 2. Место в интерфейсе

Вкладка `Дашборд` открывается первой в `QTabWidget` главного окна:

1. `Дашборд`
2. `Научные материалы`
3. `Телеграммы`
4. `Задачи`
5. `Статистика`

## 3. Фильтры

Верхняя панель:

- **Период**: `Год` / `Полугодие` / `Квартал` / `Месяц`;
- **Год**: доступные годы;
- **Полугодие / квартал / месяц**: зависит от типа периода;
- **Финансовый год (окт–сен)**: переключатель, включён по умолчанию и подсвечен;
  при выборе календарного года подсветка снимается;
- **Филиал** (только головной офис): «Все филиалы» или конкретный филиал;
- **Обновить**: ручная перезагрузка (слева); справа показана текущая дата и день недели.

Период по умолчанию — текущий финансовый год. Для задач учитывается пересечение
срока задачи с выбранным диапазоном.

## 4. Компоновка

```
┌──────────────────────────────────────────────────────────────────────┐
│ Период: [Год ▾] [2026 ▾]  [ ] фин. год   Филиал: [Все ▾]  [Обновить]│
│ 01.01.2026–31.12.2026                                                │
├──────────────────────────────────────────────────────────────────────┤
│ ┌───────────────┐ ┌───────────────┐ ┌───────────────┐                │
│ │ Документы     │ │ Оценено       │ │ Задачи        │  (+ изменения  │
│ │ 55            │ │ 56 %          │ │ 6 / 0         │   для филиала) │
│ └───────────────┘ └───────────────┘ └───────────────┘                │
├──────────────────────────────────────────────────────────────────────┤
│ ┌─────────────────────────────┐ ┌──────────────────────────────────┐ │
│ │ Документы по месяцам        │ │ Структура по типам   [Материалы] │ │
│ └─────────────────────────────┘ └──────────────────────────────────┘ │
│ ┌─────────────────────────────┐ ┌──────────────────────────────────┐ │
│ │ Оценки                       │ │ Эффективность филиалов/отделов   │ │
│ └─────────────────────────────┘ └──────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────┘
```

Вкладка целиком помещается в окно: `QScrollArea` не используется. Размер карточек,
шрифтов и диаграмм пересчитывается при изменении окна (масштаб 0,72–1,35).
Нижних таблиц «Последние документы» и «Требуют внимания», блока файлов последнего
импорта и KPI последнего импорта нет.

## 5. Карточки KPI

Карточка: название, крупное значение и пояснение.

### 5.1. Документы за период

- количество научных материалов и телеграмм, у которых дата документа
  (`outgoing_date` или `incoming_date`) попадает в период;
- пояснение: «Материалов: N; Телеграмм: M»;
- изменение к предыдущему периоду той же длины, если он не пуст.

### 5.2. Оценено документов

- доля документов с последней оценкой (`latest_evaluation`) от общего числа;
- пояснение: «Средняя оценка: X» — среднее весов оценок (`enum_weight`).

### 5.3. Задачи

- значение: «назначено / не распределено»;
- для головного офиса — задачи, назначенные регионам и ниже;
- для филиала — задачи в области филиала;
- не распределено — задача есть у узла, но не назначена ни одному его потомку.

### 5.4. Изменения (только филиал)

- количество записей `changes` — неэкспортированные изменения;
- подсказка о необходимости экспорта перед отправкой в головной офис.

## 6. Диаграммы

Все диаграммы — PyQtChart; цвета берутся из текущей темы.

### 6.1. Документы по месяцам

Столбчатая диаграмма: материалы и телеграммы по месяцам периода. Для периода
«Месяц» — один столбец, «Квартал» — 3, «Полугодие» — 6, «Год» — 12. Подписи
месяцев сокращённые и наклонены, чтобы не перекрываться на узком окне.

### 6.2. Структура по типам

Круговая диаграмма (donut) по типам материалов или телеграмм. Переключатель
«Материалы / Телеграммы» расположен над диаграммами и выравнивает оба верхних
графика по одной линии.

### 6.3. Оценки

Столбцы по кодам `Б`, `И`, `П`, `В`. Над столбцами — количество оценок и доля
от их общего числа, например `2 (40%)`. Цвета меняются от красного (`Б`)
к зелёному (`В`). При отсутствии оценок — заглушка «Нет оценок за период».

### 6.4. Эффективность филиалов/отделов

Для головного офиса — филиалы, для филиала — отделы; количество документов
за период, сортировка по убыванию.

## 7. Поведение

- при открытии вкладки данные загружаются один раз;
- смена периода, года, подпериода, финансового года или филиала перезагружает данные;
- после экспорта/импорта ZIP, импорта справочников и импорта оценок главное окно
  вызывает `dashboard.refresh()`;
- при смене темы карточки и диаграммы перерисовываются;
- ошибки чтения выводятся в строке состояния; пустые данные — заглушками;
- дашборд только читает данные и не создаёт `Change`.

## 8. Данные и архитектура

- `reports/dashboard_service.py`:
  - `DashboardFilter(period_type, year, half, quarter, month, financial, branch_id)`;
  - `DashboardData` — KPI, месячная серия, типы, оценки, рейтинг;
  - `DashboardService(session, role, branch_id).load(filter)`.
- Периоды переиспользуют `build_reporting_period`/`build_month_period` из
  `reports/statistics_service.py`.
- `gui/dashboard_widget.py` — фильтры, KPI-карточки, четыре диаграммы,
  адаптивный масштаб и `apply_theme()`.
- `gui/application.py` — вкладка первой, обновление после импорта/экспорта.

## 9. Проверка

- `tests/test_dashboard.py` — расчёты сервиса, KPI, диаграммы, отсутствие
  `QScrollArea`, масштабирование при изменении окна, ролевой фильтр филиала.
- Полный `pytest tests -q` — 437 passed (на момент реализации).
- Дымовой запуск `MainWindow` в native-режиме: пять вкладок, данные за 2026 год.
