# Вкладка «Дашборд»

Статус: реализовано (2026-11-23). Документ описывает фактическую вкладку,
источники данных и поведение при изменении размера окна.

## 1. Назначение

«Дашборд» — обзорный экран для быстрой оценки состояния работы за выбранный период.
Он не заменяет вкладку «Статистика» и отвечает на вопросы «сколько сделано», «как
распределены задачи» и «как меняется динамика» без построения таблиц вручную.

Вкладка доступна обеим ролям:

- филиал видит только свой филиал;
- головной офис видит все филиалы и может выбрать один в фильтре.

## 2. Место в интерфейсе

Вкладка `Дашборд` открывается первой в `QTabWidget` главного окна:

1. `Дашборд`
2. `Научные материалы`
3. `Телеграммы`
4. `Задачи`
5. `Статистика`

## 3. Фильтры

Верхняя панель:

- **Период**: `Год` / `Полугодие` / `Квартал` / `Месяц`;
- **Год**: доступные годы;
- **Полугодие / квартал / месяц**: зависит от типа периода;
- **Финансовый/календарный год**: переключатель, включён по умолчанию и подсвечен.
  Надпись на кнопке показывает выбранный диапазон: «Фин. год (окт 2026-сен 2027)»
  или «Календ. год (янв-дек 2026)»; при выборе календарного года подсветка снимается;
- **Филиал** (только головной офис): «Все филиалы» или конкретный филиал;
- **Обновить**: ручная перезагрузка (слева); рядом — «Сохранить» (экспорт в DOCX);
- под фильтрами: слева карточка «Уведомления» с бегущей строкой, справа —
  карточка с текущей датой и днём недели в одну строку. Ширина уведомлений
  адаптивна, ширина карточки даты фиксирована (270 px).

Период по умолчанию — текущий финансовый год. Для задач учитывается пересечение
срока задачи с выбранным диапазоном.

## 4. Компоновка

```

│ [Обновить] [Сохранить] Период: [Год ▾] [2026 ▾] [Фин. год …]        │
│ Филиал: [Все ▾]                                                      │
│ ┌──────────────────────────────────────────────┐ ┌─────────────────┐ │
│ │ Уведомления: бегущая строка                   │ │ 22.11.2026, …   │ │
│ └──────────────────────────────────────────────┘ └─────────────────┘ │
├──────────────────────────────────────────────────────────────────────┤
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐      │
│ │Документы │ │Оценено   │ │Доложено  │ │Задачи    │ │Выполнено │      │
│ │9         │ │5         │ │3         │ │6         │ │3 (50 %)  │      │
│ └──────────┘ └──────────┘ └──────────┘ └──────────┘ └──────────┘      │
├──────────────────────────────────────────────────────────────────────┤
│ ┌─────────────────────────────┐ ┌──────────────────────────────────┐ │
│ │ Документы по месяцам        │ │ Выполнение задач                 │ │
│ └─────────────────────────────┘ └──────────────────────────────────┘ │
│ ┌─────────────────────────────┐ ┌──────────────────────────────────┐ │
│ │ Оценки                       │ │ Эффективность филиалов/отделов   │ │
│ └─────────────────────────────┘ └──────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────┘
```

Вкладка целиком помещается в окно: `QScrollArea` не используется. Размер карточек,
шрифтов и диаграмм пересчитывается при изменении окна (масштаб 0,72–1,35).
Высота диаграмм увеличена примерно на четверть относительно прежней компоновки.
Нижних таблиц «Последние документы» и «Требуют внимания» и KPI последнего
импорта нет.

## 4.1. Файлы последнего импорта — док-панель (только головной офис)

Таблица файлов, восстановленных последней операцией импорта ZIP, вынесена в
отдельную док-панель `ImportedFilesWidget` (`gui/imported_files_widget.py`),
оформленную по образцу панели прикреплённых файлов: заголовок, закрытие,
перетаскивание во все области главного окна и отрыв в плавающее окно
(`DockWidgetClosable | DockWidgetMovable | DockWidgetFloatable`, `Qt.AllDockWidgetAreas`),
поле поиска над таблицей. В раскладку вкладки «Дашборд» панель не входит.

Правила показа заданы в `gui/application.py` (`_update_docks_visibility`):

- панель создаётся только при роли «головной офис» — в филиале её нет ни в
  интерфейсе, ни в меню;
- панель видна только при активной вкладке «Дашборд»; при переходе на другую
  вкладку она скрывается и возвращается при возврате на дашборд;
- пункт «Вид» → «Файлы последнего импорта» (`QAction` с `objectName`
  `importedFilesDockAction`) включает и отключает панель; снятая галочка
  переживает переключение вкладок и перезапуск;
- при показе панели манифест перечитывается, а после импорта пакета главное
  окно вызывает `_refresh_imported_files_dock()`.

Колонки: **Имя файла** (значок из `QFileIconProvider` и имя с расширением),
**Филиал** (наименование филиала документа), **Тип документ** (метка типа
документа — научный материал или телеграмма), **Номер и дата исходящего** в
формате «Исходящий номер от ДД.ММ.ГГГГ». Данные берутся из базы: манифест
`last_import_files.json` хранит первичные ключи записей `FileRecord`, а филиал,
тип и реквизиты — из документа файла (последний по дате исходящего номера).
Имя файла занимает свободное место панели, колонки реквизитов имеют штатную
ширину и сокращают текст многоточием; полный текст любой ячейки показывается
во всплывающей подсказке. Начальная ширина панели (420 px) вмещает все четыре
колонки без горизонтальной прокрутки.

- строки упорядочены по алфавиту имени файла;
- поиск — подстрока (без regex) по всем колонкам;
- двойной щелчок открывает файл средствами ОС;
- перетаскивание во внешние приложения отдаёт URL файлов (проводник копирует);
- контекстное меню: «Расположение файла», «Переименовать» (обновляет файл
  на диске и запись БД), «Удалить файл» (убирает файл с диска и ключ из
  манифеста);
- отсутствующий на диске файл остаётся в таблице зачёркнутым;
- пустой манифест и записи старого формата (относительные пути) показывают
  заглушку «Файлы последнего импорта отсутствуют.».

## 5. Карточки KPI

Карточка: название, крупное значение и пояснение. Название и пояснение
масштабируются вместе с окном: базовые размеры — 12 и 11 pt, значение — 24 pt.
Верхний и нижний внутренние отступы карточки уменьшены до 5 px (в масштабе),
чтобы содержимое занимало больше полезной высоты.

### 5.1. Документы за период

- количество научных материалов и телеграмм, у которых дата документа
  (`outgoing_date` или `incoming_date`) попадает в период;
- пояснение: «Материалов: N; Телеграмм: M»;
- изменение к предыдущему периоду той же длины, если он не пуст.

### 5.2. Оценено документов

- значение — количество оценённых документов: оценённые научные материалы плюс
  оценённые телеграммы (`latest_evaluation` не пуста);
- процент — отношение этого количества к сумме всех научных материалов и
  оценённых телеграмм за период;
- пояснение: «X % · Средняя оценка: Y» — среднее весов оценок (`enum_weight`);
- предупреждение: «Не оценено материалов: N» — научные материалы без оценки.

### 5.3. Доложено телеграмм

- значение — количество телеграмм с заполненным типом доклада (`report_type`);
- пояснение — разбивка по типам: «ДР: N · СДР: M»;
- предупреждение: «Не доложено: N» — телеграммы без типа доклада.

### 5.4. Задачи

- значение — общее число задач периода;
- пояснение — разбивка по типам: «ОЗ: N · ДЗ: M»;
- для головного офиса задача считается распределённой, если назначена региону;
- для филиала — если назначена вплоть до сотрудника;
- предупреждение: «Не распределено: N» — задачи, не дошедшие до нужного уровня.

### 5.5. Выполнено задач

- значение — количество задач с истёкшим сроком (`end_date` раньше текущей даты)
  и в скобках процент от общего числа задач периода;
- пояснение — разбивка выполненных задач по типам: «ОЗ: N · ДЗ: M»;
- предупреждение: «Не выполнено: N» — задачи периода без истёкшего срока.

### 5.6. Изменения (только филиал)

- количество записей `changes` — неэкспортированные изменения;
- подсказка о необходимости экспорта перед отправкой в головной офис.

### 5.7. Уведомления

Карточка без заголовка, высотой с карточку даты, занимает всё свободное
пространство слева от неё. Внутри — бегущая строка (шаг 2 px каждые 35 мс,
бесшовный цикл). Постоянно выводятся:

- «Не экспортировано записей: N» — количество записей `changes`;
- «Последний экспорт: дата/нет» — самый свежий файл в каталоге экспорта;
- «Истекает срок выполнения N задач» — задачи со сроком в ближайшие 30 дней;
- «Просрочено задач: N».

Дополнительно при ненулевом значении: «Не оценено материалов», «Не доложено
телеграмм», «Не распределено задач», «Ошибки импорта».

### 5.8. Сохранение в DOCX

Кнопка «Сохранить» открывает диалог выбора файла (`Дашборд_ГГГГ-ММ-ДД.docx`)
и формирует документ: заголовок, период, дата, таблица KPI
(Показатель / Значение / Детали), текст уведомлений и четыре диаграммы,
снятые с виджетов как изображения (ширина 16,5 см). Ошибки записи показываются
в диалоговом окне.

## 6. Диаграммы

Все диаграммы — PyQtChart; цвета берутся из текущей темы.

### 6.1. Документы по месяцам

Столбчатая диаграмма: материалы и телеграммы по месяцам периода. Для периода
«Месяц» — один столбец, «Квартал» — 3, «Полугодие» — 6, «Год» — 12. Подписи
месяцев сокращённые и наклонены, чтобы не перекрываться на узком окне.

### 6.2. Выполнение задач

Столбчатая диаграмма по филиалам (для головного офиса) или отделам (для филиала).
Для каждого элемента рядом показаны два столбца: назначенные и выполненные задачи.
Каждый столбец по высоте разделён на сегменты ОЗ и ДЗ; внутри сегментов —
контрастное числовое значение, над группой — процент выполнения. Оси: вертикальная —
количество задач, горизонтальная — филиалы или отделы. Шрифты подписей — как у
диаграммы эффективности. Под диаграммой — легенда: «ОЗ — Назначено»,
«ДЗ — Назначено», «ОЗ — Выполнено», «ДЗ — Выполнено»; выполненные сегменты светлее.
Переключателя «Материалы / Телеграммы» больше нет.

### 6.3. Оценки

Столбцы по кодам `Б`, `И`, `П`, `В`. Над столбцами — количество оценок и доля
от их общего числа, например `2 (40%)`. Цвета меняются от красного (`Б`)
к зелёному (`В`). Подписи над столбцами увеличены на 3 pt. При отсутствии
оценок — заглушка «Нет оценок за период».

### 6.4. Эффективность филиалов/отделов

Для головного офиса — филиалы, для филиала — отделы; количество документов
за период, сортировка по убыванию. Заголовок зависит от разреза:
«Эффективность филиалов» или «Эффективность отделов».

Внутри основного столбца каждого элемента показываются до пяти столбцов
лучших подразделений следующего уровня (для филиала — отделы, для отдела —
сотрудники). Высота вложенного столбца пропорциональна его количеству и не
превышает высоту основного; подпись повёрнута вертикально, прижата к нижнему
краю столбца и центрирована по его ширине. Подпись нарисована белым цветом
с чёрным контуром, шрифт увеличен на 2 pt. Основные и вложенные столбцы
различаются по цвету: основной — светлый акцентный, вложенные — насыщенные;
на тёмной теме основной столбец окрашен в `#4F6B92`, вложенные — в яркую
палитру. Над основным столбцом показан числовой коэффициент — количество
документов за период.

## 7. Поведение

- при открытии вкладки данные загружаются один раз;
- смена периода, года, подпериода, финансового года или филиала перезагружает данные;
- после экспорта/импорта ZIP, импорта справочников и импорта оценок главное окно
  вызывает `dashboard.refresh()`;
- при смене темы карточки и диаграммы перерисовываются;
- ошибки чтения выводятся в строке состояния; пустые данные — заглушками;
- дашборд только читает данные и не создаёт `Change`;
- панель файлов последнего импорта перечитывает манифест при каждом показе и
  после импорта пакета.

## 8. Данные и архитектура

- `reports/dashboard_service.py`:
  - `DashboardFilter(period_type, year, half, quarter, month, financial, branch_id)`;
  - `DashboardData` — KPI, месячная серия, `task_execution`, оценки, рейтинг,
    `last_export`;
  - `DashboardService(session, role, branch_id, storage_root=None).load(filter)`.
- Периоды переиспользуют `build_reporting_period`/`build_month_period` из
  `reports/statistics_service.py`.
- `gui/dashboard_widget.py` — фильтры, KPI-карточки, карточка уведомлений
  с бегущей строкой, четыре диаграммы, адаптивный масштаб, `apply_theme()`
  и сохранение в DOCX (`save_docx`).
- `gui/application.py` — вкладка первой, обновление после импорта/экспорта,
  передача `storage_path_obj()` для поиска последнего экспорта, создание
  док-панели файлов последнего импорта и правила её показа
  (`_update_docks_visibility`), сохранение состояния обоих доков в настройках
  (`_save_dock_state`/`_restore_dock_state`).
- `gui/imported_files_widget.py` — док-панель файлов последнего импорта: модель
  `ImportedFilesTableModel` (4 колонки, MIME `text/uri-list` для drag-out),
  фильтр `QSortFilterProxyModel` (подстрока по всем колонкам); манифест —
  `read_import_manifest`/`write_import_manifest` из `importexport/import_service.py`
  (элементы — строковые UUID записей `FileRecord`).
